## 优先：复测拆除

在新一局准备阶段进行，避免胜负结算后的操作冻结，也避免生产干扰退款观察。

1. 在空地建一堵墙（4 铜），点“拆除”。刚建墙的选择应保留，墙上出现红框与叉号，面板显示返还 2 铜；点“确认拆除”，墙消失、铜增加 2。
2. 再建一堵墙，点“取消 / 浏览”，先点“拆除”、再点墙、再“确认拆除”，应同样成功。
3. 选中拆除目标后点“取消 / 浏览”，墙应保留且不退款。拆除模式点核心应提示“核心不可拆除”；点空地应提示没有建筑。
4. 暂停后确认拆除，提示操作已排队，墙仍在；点击“继续”后拆除并只返还一次。胜负结算后禁止再改建筑，需要重开。

若仍无法拆除，请提供：当时是否暂停/已结算、点击顺序、按钮或提示文字、目标建筑类型；有截图可一起附上。

## 随后：操作与反馈

| 检查 | 操作与预期 |
| --- | --- |
| 铺带取消 | 拖出一条预览，取消后预览消失、不扣铜；重新预览并确认可以建造 |
| 钻头方向 | 建钻头并在浏览模式选中，旋转后图上的输出箭头与面板一致 |
| 镜头 | 浏览模式拖动地图，松手不应误选另一建筑；点击仍可选择，缩放/归位后仍能正确选格 |
| 受击 | 战斗中让墙或核心受伤，建筑应短暂闪红并显示损伤血条 |
| 断供与重铺 | 敌人仍存活时拆掉炮塔供弹线中间一格，炮塔应先消耗真实缓存；弹药耗尽后显示 `!`，选择炮塔可见“缺弹”。在原缺口补带后，等铜运输到达，有射程内敌人时恢复开火 |

断供后不会立即停火：带与炮塔可能仍有库存。如果全场敌人已经清完，请重开测试，不能用无目标时不开火判断断供。当前首关压力较低，受击与缺弹场景可能需刻意安排；此项是诊断测试，不计作自然体验通过。

反馈格式：`项目 / 通过或失败 / 实际现象 / 设备（可选）`。自主建造、战斗与重开已由用户反馈通过，本轮优先补拆除与上述新增操作。
